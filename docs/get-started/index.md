# Get started

Install GraphFaker, run three commands, then move to Python when you want a schema of your own.

- [Install](install.md): `pip install graphfaker`, with the optional extras for Neo4j, LadybugDB and the notebooks.
- [Three things to try](first-commands.md): a social graph, a synthetic bank with its fraud, and a load into a database, each one command.
- [Using GraphFaker from Python](python.md): schemas, the fraud pack, writing, reading and querying, and reproducibility.
- [The tour notebook](../notebooks/graphfaker_tour.ipynb): everything in one place, with charts.
